v2.4.51: Automation Map shows how your installed Hubitat apps, rules and devices connect in an interactive graph you can explore, search and export.

Changes since v2.4.48:

* Works through Hubitat Remote Access: the map, Room Manager and the webCoRE Migration Assessment now reach the hub through the page's own address instead of Hubitat's cloud relay, which was slow and failed on large replies. Links to the hub's own pages work through Remote Access too. If the Remote Access sign-in has lapsed, the page says so instead of showing an error.
* A Rule Machine Variable condition that compares with another variable is now read with that variable, so HAI can convert it; it was read as having no value.

After upgrading: the settings page asks you to run a scan. If you use HAI's migration, keep the daily scan on, or scan again before migrating, so HAI reads your rules as they are now.
