v2.4.2: Automation Map shows how your installed Hubitat apps, rules and devices connect in an interactive graph you can explore, search and export. It now also groups devices by room.

Changes since v2.3.2:

- Room Manager: Arrange rooms as movable, resizable rectangles with device icons inside them. Devices without a room appear in a "Not Allocated" column. Drag devices into rooms, use Ctrl-click or Shift-click to select several, and create, rename or delete rooms without leaving the page. Changes remain staged until you press Apply. Discard removes staged changes, and failed changes remain staged so you can retry only those items.
- Hub writes are limited to room membership: Automation Map changes only which room a device belongs to. It does not send any other field of the device record, so nothing else about the device can be altered by a room change. This is Automation Map's first release that writes to the hub. Room Manager does not command devices, edit rules or change other apps. Deleting a room leaves its devices intact and unallocated, with a confirmation showing how many will be affected.
- Experimental HAI integration: Hubitat Automation Intelligence Engine can now appear on the map. Hubs without HAI continue to use Automation Map normally.
- HAI RM5 Coverage report: Compare Rule Machine 5.1 and HAI capabilities, see which HAI capabilities have been observed running on a hub, and see which capabilities your own rules use.
- webCoRE Migration Assessment: Adds an HAI Engine rating alongside Rule Machine and Visual Rule Builder.
- Read-only relationship API: Other apps can retrieve Automation Map's device relationships.
- Easier-to-read flowcharts: Diagrams open in a wider panel that adjusts when you zoom or resize the browser.
- Faster map opening: The flowchart library now loads when you first open a flowchart, removing about 3 MB from the initial map load.
- Better phone layout: The link to open the map now appears above the Scan button.

After upgrading: Run a rescan to refresh app tags.
