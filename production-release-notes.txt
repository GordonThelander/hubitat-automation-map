v2.3.1: Automation Map visualizes how your installed Hubitat apps and devices relate to each other, showing which app owns which device, what triggers or constrains a rule, and how everything connects, as an interactive graph you can explore, search, and export.

Since the last production release (2.3.0):

- New webCoRE migration assessment. Select a webCoRE piston and press the Migration assessment button to see how directly it maps onto Rule Machine and onto Visual Rule Builder, rated from 1 (direct equivalent, simple) to 5 (easier to rebuild from scratch), with each part that needs rework and the change it needs.
- Where the only difference is that a repeated device event could run the rule again, and the piston only sends fixed-value commands such as turning lights on or setting a level, the assessment shows a warning instead of rework. A piston with a part the assessment does not recognise is shown as Not assessed rather than given a guessed rating.
- The new webCoRE Migration Assessment button in the control panel opens a report covering every piston on the hub, with a summary for each engine, level filters, a table of how each webCoRE construct maps, and CSV downloads.

Privacy: the assessment only reads each piston's saved structure. No variable value, message or device label is read, and nothing is created or changed on the hub.
